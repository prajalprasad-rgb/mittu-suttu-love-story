# Luxury Romantic Website

A premium, cinematic romantic website built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Personalize

Edit `src/lib/content.ts` to replace names, dates, photos, voice message copy, letters, bucket list items, and story timeline details.

## Deploy

Push to GitHub and import the project into Vercel. The app uses the Next.js app router and is ready for Vercel deployment.
